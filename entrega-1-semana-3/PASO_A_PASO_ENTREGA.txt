A. PREPARAR EL PAQUETE DEFINITIVO
1. Descarga Entrega_1_Semana_3_Gestor_Tareas.zip y selecciona Extraer todo.
   No ejecutes los archivos desde dentro del ZIP.
2. Instala Docker Desktop desde https://www.docker.com/products/docker-desktop/
   si aun no lo tienes. Atiende sus indicaciones de WSL 2 o reinicio. Abre
   Docker Desktop y espera a que el motor este activo.
3. Entra a la carpeta extraida que contiene compose.yaml y Dockerfile.
4. Haz doble clic en PREPARAR_ENTREGA.bat. Necesita Internet la primera vez.
   No necesitas instalar Python ni programar. La ventana muestra el avance.
5. El programa construye e inicia web y datos, comprueba su estado, verifica
   la red comun, ejecuta nueve pruebas, escribe una tarea desde web y la lee
   directamente desde Redis. Luego recrea los dos contenedores y comprueba
   que el dato siga presente en el volumen.
6. Solo si todo pasa, muestra VALIDACION DOCKER APROBADA y abre una carpeta
   dentro de entrega_para_subir. Alli esta:
   Entrega_1_Semana_3_Johan_Alvarez_Parra.zip
7. Ese ZIP contiene el informe PDF y Word, codigo y evidencias_docker con
   resultado_docker.json y los registros reales. No debes editar el informe
   ni completar nombres: los datos academicos ya estan diligenciados.
8. Puedes abrir http://localhost:5000 para ver la aplicacion. DETENER.bat
   permite apagar los contenedores sin eliminar el volumen ni las evidencias.

Si aparece un error rojo: no se genera un nuevo paquete aprobado. Busca
ERROR.txt en la subcarpeta indicada de evidencias y envialo para corregirlo.
Si ya habia un ZIP aprobado de otro intento, no confundirlo con el intento
fallido: cada ejecucion usa una carpeta con fecha y un identificador propio.

B. SUBIR EL TRABAJO AL AULA
1. Ingresa al aula y abre Enfasis Profesional I (Integracion Continua).
2. Busca la actividad Entrega 1 - Semana 3 del escenario correspondiente.
   Comprueba el nombre; no uses Entrega 2 - Semana 5.
3. Abre la opcion para agregar o cargar una entrega. El nombre de los botones
   puede variar porque no se ha inspeccionado tu aula virtual.
4. Si acepta ZIP, adjunta Entrega_1_Semana_3_Johan_Alvarez_Parra.zip generado
   DESPUES de la validacion. No subas el ZIP de preparacion como si incluyera
   pruebas Docker aprobadas.
5. Si permite varios archivos, puedes adjuntar tambien el PDF de esa misma
   carpeta. El Word se incluye como respaldo editable.
6. En el campo de texto o comentarios, pega el mensaje de la seccion C.
7. Si el aula no acepta ZIP, adjunta el informe PDF y el enlace de GitHub.
   Incluye tambien las evidencias Docker en el formato permitido. Si solo
   admite un PDF y no deja enlazar ni adjuntar evidencias, primero pide a tu
   profesor un medio para el codigo y el anexo; no omitas esos componentes.
8. Guarda los cambios y confirma Enviar entrega/Enviar tarea si aparece ese
   paso. Revisa que figure Entregado/Enviado para calificar, no solo Borrador.
9. Abre los adjuntos desde el aula y comprueba que se vean el informe y el ZIP.
   Conserva el comprobante o una captura de la confirmacion de envio.
