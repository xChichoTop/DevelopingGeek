Lee PASO_A_PASO_ENTREGA.txt.
Abre Docker Desktop y haz doble clic en PREPARAR_ENTREGA.bat.
El programa comprueba los dos contenedores y solo genera el ZIP definitivo
si todas las verificaciones pasan. Los nombres ya estan completos.

El ZIP definitivo se guarda dentro de entrega_para_subir, en una subcarpeta
con fecha e identificador. Ese es el archivo que debes subir al aula.

Antes de ejecutar esa comprobacion, el proyecto tiene pruebas reales locales,
pero no una validacion Docker aprobada. El bloqueo de GitHub Actions no impide
hacer la prueba en Docker Desktop.
