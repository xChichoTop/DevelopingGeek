ENTREGA 1 - SEMANA 3

1. Lee el informe en la carpeta informe. Completa los nombres de integrantes y docente.
2. Para comprobar Docker en tu computador: instala y abre Docker Desktop; haz doble clic en INICIAR.bat y luego VERIFICAR.bat.
3. Para comprobar Docker en GitHub sin instalarlo en tu computador: sube los archivos a la raíz de un repositorio GitHub. Es indispensable incluir .github/workflows/verificar-docker.yml.
4. En GitHub abre Actions > Comprobar dos contenedores Docker. Espera la ejecución. Si finaliza correctamente, descarga el artefacto evidencias-dos-contenedores.
5. Agrega al informe la URL real del repositorio y los resultados de Docker. Cambia el estado pendiente únicamente después de observar los resultados reales.
6. Entrega el informe y el enlace al repositorio. Adjunta el ZIP si el aula lo permite.
